## Required Sections

Each feature spec MUST include:
- Purpose;
- Syntax;
- Parsing Rules;
- AST;
- Serialization;
- Editor Behavior;
- Workspace Behavior;
- Conflicts;
- Diagnostics;
- Fixtures;
- Acceptance Criteria.

## Forbidden Feature Specs

These files MUST NOT exist in v0:
- `kbd.md`
- `components.md`
- `attributes.md`
