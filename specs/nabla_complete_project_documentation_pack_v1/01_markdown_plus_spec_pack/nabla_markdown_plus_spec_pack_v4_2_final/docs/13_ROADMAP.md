
# Roadmap

## Phase 0 — v4 Spec Pack

Exit criteria:
- coverage matrix is honest;
- diagnostic snapshot policy exists;
- critical fixture expansion exists before parser implementation;
- block id attachment is specified;
- callout/toggle child grammar is specified.

## Phase 1 — Fixture Expansion Before Implementation

Exit criteria:
- frontmatter fixtures exist;
- block id critical fixtures exist;
- transclusion missing/depth fixtures exist;
- callout/toggle child fixtures exist;
- highlight invalid/unclosed fixtures exist;
- task unsupported marker fixture exists;
- wiki combined grammar fixtures exist.

## Phase 2 — Core Types

Implement TypeScript AST and diagnostics.

## Phase 3 — Parser Skeleton

Implement protected regions and baseline parser integration.

## Phase 4 — Serializer Skeleton

Implement canonical serializer.

## Phase 5 — Connected Notes

Implement wiki links, tags, block ids.

## Phase 6 — Workspace

Implement file, heading, block, backlink, transclusion indexes.

## Phase 7 — Visual Blocks

Implement callouts, toggles, folded headings.

## Phase 8 — Inline Extras

Implement tooltips, highlights, emoji, comments, footnotes.

## Phase 9 — Stabilization

Expand remaining fixtures and remove regressions.
